# ポッチ工房

ブラウザで動くブロック工作アプリです。3D モデル (.glb / .gltf / .obj / .fbx / .stl / .ply) をブロックに変換し、
組み立て順に 1 段ずつ・1 個ずつ見たり、LDraw (.ldr) や部品表に書き出したりできます。

**使う: https://oshima1214.github.io/pocchi-kobo/**

- インストール不要。パソコンでもスマホでも、ブラウザで開くだけで使えます。
- ひらいた 3D モデルや作ったものは、使っている人のブラウザの中だけで処理します (どこにも送りません)。
- 画面右上の「?」に操作の一覧があります。
